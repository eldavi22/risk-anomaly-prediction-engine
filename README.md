**Risk Anomaly Prediction Engine**

I built this project to explore how machine learning can help spot unusual patterns in risk data. The model is written in Python using NumPy and SciPy, with the learning and optimization steps implemented directly rather than through a ready-made machine learning framework.

It works with simulated data, trains a nonlinear classifier, and checks how well it identifies potential anomalies. I also included tests for the calculations and training process so the results can be checked and reproduced.

To try it, install the packages in `requirements-risk-anomaly.txt` and run `python risk_anomaly_lbfgsb.py`. The code is shared under the MIT license.
